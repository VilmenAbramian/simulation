# 📁 experiments — Jupyter-блокноты и графики

Папка `experiments` содержит Jupyter-блокноты, которые позволяют запускать, настраивать и визуализировать работу симуляционных моделей проекта `pysim`. Они используются как для демонстрации работы моделей, так и для подготовки графиков и анализа данных для кандидатской диссертации.

Блокноты служат трем основным целям:

1. 🧪 Демонстрация запуска моделей и примеров конфигурации.
2. 📊 Построение графиков для научных публикаций, презентаций и диссертации.
3. 📚 Объяснение теоретических предпосылок используемых формул и алгоритмов.

Это удобный инструмент для понимания внутренней логики моделей и генерации исходных изображений для кандидатской диссертации.

## 📓 Блокноты  
  
| Название файла                 | Назначение                                                                                                               |  
|--------------------------------|--------------------------------------------------------------------------------------------------------------------------| 
| `3d_model_of_UAV_system.ipynb` | 3D-визуализация геометрии RFID системы на БПЛА                                                                           |
| `channel.ipynb`                | Анализ канала для RFID системы на БПЛА                                                                                   |
| `hybrid.ipynb`                 | Имитационная оценка вероятности успешной идентификации автомобиля гибридной системой (RFID + БПЛА)  
| `rfid_adjust.ipynb`            | Имитационная оценка вероятности и времени чтения RFID меток в условиях коллизий с использованием QueryAdjust             |
| `rfid_multiple_tag.ipynb`      | Имитационная оценка вероятности и времени чтения RFID меток в условиях коллизий без использования QueryAdjust            |
| `rfid_single_tag.ipynb`        | Имитационная оценка вероятности и времени чтения RFID метки со считывателя, установленного на БПЛА в случае без коллизий |   
| `tag_time_graphs.ipynb`        | Аналитическая оценка времени чтения RFID метки со считывателя, установленного на БПЛА в случае без коллизий              |

## 📂 Подкаталоги  

- `notebooks/`
  В папке находятся все Jupyter-блокноты с экспериментами.
- `results/`
  Внутри папки находятся все результаты экспериментов из папки `notebooks/`. Для удобства внутри находится 2 директории:
    - `result_images/`
      Содержит все изображения, автоматически сохраняемые из блокнотов. Каждый блокнот сохраняет свои изображения в свою отдельную папку.
    - `result_jsons/`  
      Хранилище JSON-файлов с результатами моделирования, используемых для построения графиков. Делится на подкаталоги по моделям.

- `utility/`    
  Вспомогательные модули и ресурсы:
    - `img/` — папка с изображениями для markdown-вставок в блокнотах.
    - `channel_helper.py` — вспомогательная логика для аналитического расчёта беспроводного RFID канала.
    - `graphs_style.py` — стилизация и сохранение графиков, настройка глобальных параметров визуализации.
    - `hybrid_helper.py` - запуск и визуализация результатов для модели hybrid.
	- `rfid_helper.py` - запуск и визуализация результатов для модели RFID.

## 🧩 Использование  
  
1. Откройте нужный `.ipynb` файл в Jupyter Notebook, JupyterLab или VS Code.
2. Запустите ячейки по порядку.
3. Изображения сохраняются автоматически с помощью функции `savefig(...)` в `result_images/...`.
